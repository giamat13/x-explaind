This only decides whether the hacker gets onto your network at all — a weak password really can go either way. Reading the message itself is never part of that bet: it always stays blocked by end-to-end encryption, whether they get in or not.

📥 Your chat backup (Google Drive / iCloud)

This is the one real way old messages do get exposed — not by catching them on the way, but from an unencrypted backup sitting in your cloud account. If a hacker breaks into that account, an unencrypted backup opens right up. It has nothing to do with the message crossing the internet, and turning on encrypted backups (WhatsApp Settings → Chats → Chat backup) closes it completely.
